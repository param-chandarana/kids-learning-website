# Kids Interactive Learning Website

An engaging and educational Next.js frontend designed for children, offering interactive learning experiences across subjects like Math, Science, English, Art, and more. Parents can monitor their child’s progress through a dedicated dashboard. Optimized for performance, accessibility, and SEO to ensure a smooth experience across all devices.

## 🚀 Features

### 📚 Subjects & Topics
- Multiple subjects: **Math**, **Science**, **English**, **Art**, and more
- Each subject includes various **topics** structured for different learning levels

### 📖 Learning Materials
- Topic-based **reading materials** designed with child-friendly fonts and layouts
- **Downloadable PDF worksheets** for offline learning and practice
- **Video resources** curated from educational platforms

### 🎮 Interactive Games & Quizzes
- Subject-specific **quizzes and mini-games** to make learning fun and interactive
- Gamified scoring to encourage engagement and retention

### 👨‍👩‍👧 Parent Dashboard
- Login for parents to:
  - **Track child’s progress**
  - View subject-specific performance and activity history

### 🌐 Optimized for Web
- **Built with Next.js** for fast performance and server-side rendering
- **SEO optimized** with proper meta tags
- **Accessible UI** designed with children in mind
- **Responsive design** for desktops, tablets, and mobile devices

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/)
- **Styling**: Tailwind CSS
- **Deployment**: Vercel
